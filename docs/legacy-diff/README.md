# Legacy Diff Notes

Use this folder for notes when comparing the old static site with the Next.js implementation.

## Canonical Reference

- Old static HTML snapshots: `legacy/html/`
- Old static-site JavaScript: `legacy/js/script.js`
- Active Next.js pages: `app/`
- Active shared UI: `components/`
- Active styles: `styles.css` and `app/next.css`

## Comparison Rule

The old HTML is a visual and behavioral reference, but the active runtime should stay in the Next.js app.
